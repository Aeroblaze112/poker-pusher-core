# 音效目录

代码里的调用点都接好了（`scripts/game/audio.gd`），这里现在是空的，所以游戏是静音的。

把文件按下面的名字放进本目录就会出声，**不用改代码**：

| 文件名 | 什么时候响 |
| --- | --- |
| `deal.ogg` | 发牌 |
| `fix.ogg` | 玩家固定 1 张进构筑组 |
| `flip.ogg` | 弃牌（效果牌「弃」）/ 效果牌翻面 |
| `draw.ogg` | 摸牌（效果牌「摸」） |
| `gain.ogg` | 结算加分，`+N` 飞进分板 |
| `win.ogg` | 终局，你赢 |
| `lose.ogg` | 终局，你没赢 |
| `click.ogg` | 按钮（暂未接调用） |

- 认 `ogg` / `wav` / `mp3`，同优先级下优先 `.ogg`
- 时长建议都在 0.5 秒以内，加分和翻面的尤其要短，别盖住连续动作
- 音量走 Master 总线，游戏内「设置 → 主音量」调的就是它
- 想加背景音乐：丢 `theme.ogg` 进来，然后在一处调用 `Audio.play_bgm("theme")`（默认循环、-8 dB）
